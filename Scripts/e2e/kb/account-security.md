# Account security

## Resetting your password

To reset your password, open Settings > Security > Reset Password. We email a reset link that is valid for 30 minutes. If the link expires, request a new one from the same page.

## Two-factor sign-in

Two-factor sign-in is under Settings > Security > Two-factor. Admins can require it for the whole team from Admin > Policies > Require two-factor.
